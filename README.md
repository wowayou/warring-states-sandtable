# 戰國沙盤 · 先秦形勢演變

前475 — 前221，二百五十四年列国形势与战事的可交互沙盘。

一块青铜相地盘：山川是烙出来的起伏，疆域是嵌进去的矿物色，战事是朱砂十字。
拖动底部的铜尺换年，全盘随之易主；点开任一战事，镜头压到战场上，看两军沿真实路线合围。

**秦用的是全盘最冷最暗的一色**——所以它东出的两百年，看上去正是这张盘一点点暗下去的过程。

## 跑起来

纯静态，无构建依赖。

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/index.html
```

或直接用打包好的单文件（离线可用，双击即开）：

```bash
node build.mjs        # 生成 dist/index.html 与 dist/artifact.html
```

## 怎么读

二百五十四年切成**六幕**，每幕有自己的主题。铜尺上的六段就是幕，上梁与右栏「案上」始终告诉你此刻在读哪一幕、这一幕在讲什么、该看哪几场仗。

推演一场仗时，**盘面接管**：镜头压到战场，两侧退居其后，解说条贴在盘上逐步推进——一支军走完，下一支才动。眼睛只需盯着一处。

疆域易主时盘上会**闪一下**，同时浮出一行「前278 · 白起拔郢，秦置南郡」，所以变化发生在哪里不会错过。

| 操作 | 结果 |
| --- | --- |
| 推演 / 空格 | 自动纪年：平淡的年份一带而过，有事的年份驻足，遇战自动开演，演毕镜头退回全景 |
| 点铜尺上的幕 | 跳到该幕开头 |
| 拖动铜尺 / ← → | 换年（Shift + 方向键跳十年） |
| 点朱砂十字，或案上「本幕战事」 | 开演：镜头推近，解说分步推进 |
| 点疆域格 | 该地二百五十四年间的易主全历 |
| 点左栏大事记 | 跳至该年；只有当年那条会展开 |
| 滚轮 / 双指 / ＋－ | 缩放；拖动移图；复位回到全景 |
| 上梁六枚铜牌 | 开关山川起伏、水系、长城、关塞、战事、国名 |

## 数据是怎么组织的

`src/atlas.js` — 图幅。海岸线、七十余个地理单元的种子点、河渠、山脉、长城、关隘，坐标取今地经纬。
疆域不画多边形，而是给每个地理单元一个种子点，运行时求 Voronoi 分区并裁到海岸线以内。
好处是改一处归属只需改一个字段，且郡界永远闭合。

`src/history.js` — 编年。`BASE` 是前475 的全盘归属，`CHANGES` 是按年递进的差量（三家分晋、五国破齐、长平之后的上党……），
`ownerAt(year)` 折叠出任意一年的形势。`ACTS` 把这些年分成六幕。
战事除兵力与史评外，还带 `steps`（分步解说）与 `arrows`（各军行军路线）——两者一一对应，所以字幕永远和盘上正在走的那支军是同一件事。

`src/geo.js` — 投影、半平面裁剪求 Voronoi、邻接判定、样条平滑。
`src/table.js` — 沙盘渲染：高程场烙山、斜光晕渲、疆域镶嵌、兵棋、推演。
`src/app.js` — 铜尺、大事记、国力、案上详情的联动。

## 部署

纯静态，无构建产物依赖。仓库根目录直接就能发布：

- **GitHub Pages** — Settings → Pages → Source 选 GitHub Actions，已附 `.github/workflows/pages.yml`，推到 `main` 即自动发布
- **Cloudflare Pages / Vercel / Netlify** — 构建命令留空，输出目录填 `/`
- **任意静态托管 / 本地** — 把 `dist/index.html` 单独丢过去即可，它是自足的一个文件

## 关于准确度

疆域为**概貌示意**，据主流复原图简化，以事件为界分段切换，非逐年精确。
几处已知的取舍：南阳（宛）在韩楚间反复，此处取前375 入韩、前291 入秦；
上党在韩赵魏间犬牙交错，此处作前453 属韩、前262 归赵、前260 入秦；
战国初年晋公室尚存至前376，盘上则于前453 三家分晋时即撤。

「郡」为地理单元计数，非秦制三十六郡；「带甲」由地力分量折算，用以比较国势消长，不作史料引用。
