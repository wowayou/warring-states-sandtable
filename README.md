# 戰國沙盤 · 先秦形勢演變

前475 — 前221，二百五十四年列国形势与战事的可交互沙盘。

一块青铜相地盘：山川是烙出来的起伏，疆域是嵌进去的矿物色，战事是朱砂十字。
拖动底部的铜尺换年，全盘随之易主；点开任一战事，镜头压到战场上，看两军沿真实路线合围。

**秦用的是全盘最冷最暗的一色**——所以它东出的两百年，看上去正是这张盘一点点暗下去的过程。

## 跑起来

纯静态，无构建依赖。

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000/index.html
```

或直接用打包好的单文件（离线可用，双击即开）：

```bash
node build.mjs        # 生成 dist/index.html 与 dist/artifact.html
```

## 怎么读

二百五十四年切成**六幕**，每幕有自己的主题。铜尺上的六段就是幕，上梁与右栏「案上」始终告诉你此刻在读哪一幕、这一幕在讲什么、该看哪几场仗。

按下**推演**，纪年自行前进：平淡的年份一带而过，有事的年份停下来，解说条从盘底升起把这一年讲完再走。
一百条大事、三十场战役，都在盘上讲，不必去左栏找。文字长的多停一会儿，嫌慢可开**倍速**。

轮到一场仗时，**盘面接管**：镜头压到战场，两侧退居其后，解说分步推进——一支军走完，下一支才动。眼睛只需盯着一处。

疆域易主时盘上会**闪一下**，同时浮出一行「前278 · 白起拔郢，秦置南郡」，所以变化发生在哪里不会错过。

| 操作 | 结果 |
| --- | --- |
| 推演 / 空格 | 自动纪年并逐年讲解，遇战自动开演，演毕镜头退回全景 |
| 倍速 | 解说停留时长减半 |
| 朗读 | 念出解说，战事落定敲一记编钟。默认关 |
| 放映 / Esc 退出 | 纪录片模式：藏起两侧，幕起有字卡，解说压成下三分之一，镜头随所讲之处缓缓游走 |
| 点铜尺上的幕 | 跳到该幕开头 |
| 拖动铜尺 / ← → | 换年（Shift + 方向键跳十年） |
| 点朱砂十字，或案上「本幕战事」 | 开演：镜头推近，解说分步推进 |
| 点疆域格 | 该地二百五十四年间的易主全历 |
| 点左栏大事记 | 跳至该年；只有当年那条会展开 |
| 滚轮 / 双指 / ＋－ | 缩放；拖动移图；复位回到全景 |
| 上梁六枚铜牌 | 开关山川起伏、水系、长城、关塞、战事、国名 |

## 数据是怎么组织的

`src/atlas.js` — 图幅。海岸线、七十余个地理单元的种子点、河渠、山脉、长城、关隘，坐标取今地经纬。
疆域不画多边形，而是给每个地理单元一个种子点，运行时求 Voronoi 分区并裁到海岸线以内。
好处是改一处归属只需改一个字段，且郡界永远闭合。

`src/history.js` — 编年。`BASE` 是前475 的全盘归属，`CHANGES` 是按年递进的差量（三家分晋、五国破齐、长平之后的上党……），
`ownerAt(year)` 折叠出任意一年的形势。`ACTS` 把这些年分成六幕。
战事除兵力与史评外，还带 `steps`（分步解说）与 `arrows`（各军行军路线）——两者一一对应，所以字幕永远和盘上正在走的那支军是同一件事。

盘缘不是装饰：刻度、角标、**比例尺（公里与秦里）**、方位、图例，都是读图要用的东西。

## 盘面是怎么画的

一张 Voronoi 分区直接画出来，一眼就是算法：钝角、直边、大块多边形。所以每条边都沿法向加了分形扰动
（`geo.js` 的 `warpEdge`）。扰动量只取决于点的位置与边的**规范朝向**——两端点按坐标排序后再定法向——
于是相邻两格共用的那条边算出来分毫不差，不会裂缝。海岸线同样加了细皱。

起伏不是贴图：山脉骨架按宽度铺成脊线并取最大值（取最大而非累加，山才是长条而非团块），
叠两层细噪声，再作西北向斜光晕渲。陆地整体带投影与岸缘倒角，故盘上那块地是**抬起来的**，
不是平铺的色块。

七国的颜色按**明度**也拉开了差距，不只按色相——灰度下依然分得清谁是谁。
秦仍是最冷最暗的一色，但饱和度足够，不至于和化外之地混作一团。

**化外之地按「盘外」处理**：压暗、加斜纹、不参与国力。沙盘只塑造诸夏，其余是盘面的余白——
既是取舍，也是实情：那些地方本不在战国诸侯的推演之内。

## 放映

按**放映**，两侧简册与器具都收起来，只剩盘、字与年：

- **幕起有字卡**：一整屏压暗，大字打出「第三幕 · 三极与纵横」与该幕主旨，停四秒再化开。
- **解说压成下三分之一**：朱砂竖线起首，战事是朱砂，讲解是铜色，与画面同在一处。
- **镜头始终在动**：极缓的呼吸与横移（十几秒一个周期），讲到某地便**缓缓移过去**——
  一百条大事里有六十九条带了地点，所以说「商鞅变法」时镜头在咸阳，说「稷下学宫」时在临淄。
  镜头一律夹在诸夏范围之内，不会漂到海上。
- 时间轴收成底部一道细线，幕次仍分段可点；`Esc` 或再按一次即退出。

镜头缓动时盘面不逐帧重绘——先缩放缓存的那一张，按节流重画，故放映全程仍是满帧。

## 声

`src/sound.js`。不带任何音频文件：

- **朗读**用浏览器自带的 `speechSynthesis`。开启后，解说条上的字会被念出来，念完这一条才走下一年（战事则每一步单独念，并相应放慢行军节拍）。
- **编钟**用 WebAudio 现合成：基频之外叠几个不谐分音，快起慢落，只在战事落定与幕起那两个时刻敲一记。
  声音统一由「朗读」开关控制，不另设旋钮。

中文嗓音是否可用因系统而异——macOS、iOS、Windows、Android 一般都有；Linux 上的 Chrome 常常没有。
**检测不到中文嗓音时按钮会自己置灰并说明原因**，不会静默地假装在念。

## 手感

第一版逐帧全量重绘整张盘，静置时也在烧 CPU；换一年要重建一次国力面板的 DOM；
平滑滚动被逐年重启而互相打断；滚轮按固定倍率缩放，触控板一扫就冲到底。实测（同机同脚本）：

| 场景 | 改前 | 改后 |
| --- | --- | --- |
| 静置 | 帧 p95 617ms，长帧 17 | 17ms，长帧 0 |
| 自动推演 6 秒 | 长帧 67 | 2 |
| 拖动铜尺横扫全程 | 长帧 101，DOM 重建 67 | 21，重建 8 |
| 滚轮缩放 | 长帧 10 | 0 |
| 点开战役 | 帧 p95 167ms | 50ms |

做法：盘面画进离屏画布缓存，只在视角、年份、图层变了才重绘，每帧只重画会动的几层；
山痕、郡界、国界从上千次 `stroke` 合并成几条 `Path2D`；化外斜纹改用图案填充；
易主过渡改为两张盘面交叠淡出，而非逐帧重算配色；镜头飞行期间先缩放缓存的那张，落定再重绘；
拖动铜尺时不做过渡动画且重绘限流；滚轮改按位移取指数并夹住单次幅度。
`prefers-reduced-motion` 下镜头直接就位、战事标记不再脉动。

`src/geo.js` — 投影、半平面裁剪求 Voronoi、邻接判定、样条平滑。
`src/table.js` — 沙盘渲染：高程场烙山、斜光晕渲、疆域镶嵌、兵棋、推演。
`src/app.js` — 铜尺、大事记、国力、案上、解说条的联动与自动推演的节奏。
`tools/subset-font.mjs` — 把 Noto Serif CJK SC Bold 裁到本站用到的 1279 字，内嵌为 woff2，详见 [assets/README.md](assets/README.md)。

## 部署

纯静态，无构建产物依赖。仓库根目录直接就能发布：

- **GitHub Pages** — Settings → Pages → Source 选 GitHub Actions，已附 `.github/workflows/pages.yml`，推到 `main` 即自动发布
- **Cloudflare Pages / Vercel / Netlify** — 构建命令留空，输出目录填 `/`
- **任意静态托管 / 本地** — 把 `dist/index.html` 单独丢过去即可，它是自足的一个文件

## 关于准确度

疆域为**概貌示意**，据主流复原图简化，以事件为界分段切换，非逐年精确。
几处已知的取舍：南阳（宛）在韩楚间反复，此处取前375 入韩、前291 入秦；
上党在韩赵魏间犬牙交错，此处作前453 属韩、前262 归赵、前260 入秦；
战国初年晋公室尚存至前376，盘上则于前453 三家分晋时即撤。

「郡」为地理单元计数，非秦制三十六郡；「带甲」由地力分量折算，用以比较国势消长，不作史料引用。

现收战役 30 场、大事 100 条，涵盖战争、变法、纵横、兼并、迁都、学术与工程七类。
