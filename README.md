# 戰國沙盤 · 先秦形勢演變

前475 — 前221，二百五十四年列国形势与战事的可交互沙盘。

一块青铜相地盘：山川是烙出来的起伏，疆域是嵌进去的矿物色，战事是朱砂十字。
拖动底部的铜尺换年，全盘随之易主；点开任一战事，镜头压到战场上，看两军沿真实路线合围。

**秦用的是全盘最冷最暗的一色**——所以它东出的两百年，看上去正是这张盘一点点暗下去的过程。

## 怎么读

二百五十四年切成**六幕**，每幕有自己的主题。铜尺上的六段就是幕，上梁与右栏「案上」始终告诉你此刻在读哪一幕、这一幕在讲什么、该看哪几场仗。

按下**推演**，开始本地 Qwen 男声讲解，纪年自行前进：平淡的年份一带而过，有事的年份停下来，解说条从盘底升起把这一年讲完再走。
一百零一条大事（其中战役三十场），都在盘上讲，不必去左栏找。字幕与行军按实际音频位置同步；无声模式使用相同的实测时长，可选择0.75—2倍速。

轮到一场仗时，**盘面接管**：镜头压到战场，两侧退居其后，解说分步推进——一支军走完，下一支才动。眼睛只需盯着一处。

疆域易主时盘上会**闪一下**，同时浮出一行「前278 · 白起拔郢，秦置南郡」，所以变化发生在哪里不会错过。

## 数据是怎么组织的

`src/atlas.js` — 图幅。海岸线、七十余个地理单元的种子点、河渠、山脉、长城、关隘，坐标取今地经纬。
疆域不画多边形，而是给每个地理单元一个种子点，运行时求 Voronoi 分区并裁到海岸线以内。
好处是改一处归属只需改一个字段，且郡界永远闭合。

`src/history.js` — 编年。`BASE` 是前475 的全盘归属，`CHANGES` 是按年递进的差量（三家分晋、五国破齐、长平之后的上党……），
`ownerAt(year)` 折叠出任意一年的形势。`ACTS` 把这些年分成六幕。
战事除兵力与史评外，还带 `steps`（分步解说）与 `arrows`（各军行军路线）。每条路线对应一个讲解步骤，末步保留全路线并讲述战果；音频播放位置统一驱动字幕和路线进度。

盘缘不是装饰：刻度、角标、**比例尺（公里与秦里）**、方位、图例，都是读图要用的东西。

## 盘面是怎么画的

一张 Voronoi 分区直接画出来，一眼就是算法：钝角、直边、大块多边形。所以每条边都沿法向加了分形扰动
（`geo.js` 的 `warpEdge`）。扰动量只取决于点的位置与边的**规范朝向**——两端点按坐标排序后再定法向——
于是相邻两格共用的那条边算出来分毫不差，不会裂缝。海岸线同样加了细皱。

起伏不是贴图：山脉骨架按宽度铺成脊线并取最大值（取最大而非累加，山才是长条而非团块），
叠两层细噪声，再作西北向斜光晕渲。陆地整体带投影与岸缘倒角，故盘上那块地是**抬起来的**，
不是平铺的色块。

七国的颜色按**明度**也拉开了差距，不只按色相——灰度下依然分得清谁是谁。
秦仍是最冷最暗的一色，但饱和度足够，不至于和化外之地混作一团。

**化外之地按「盘外」处理**：压暗、加斜纹、不参与国力。沙盘只塑造诸夏，其余是盘面的余白——
既是取舍，也是实情：那些地方本不在战国诸侯的推演之内。

## 放映

纪录片的质感不在滤镜，在四件事上，此处逐条照办：

**一、字是主角，且极度克制。** 幕起的字卡是大字＋巨大留白＋一条发丝细线，
再压一行**宽字距全大写的西文**——`ACT I · 475–404 BC` 与 `THE FALL OF JIN`。
中文历史纪录片的片头几乎都是这个组合。主旨缩成一小段灰字，不与标题争。

**二、元素依次入场，不是一起淡入。** 细线先自左抹开，再是幕次与年限，
再是标题（**字距由松收紧**，0.5em → 0.18em），最后西文与下方细线。
解说条同样自左抹入。整个入场约一秒半，比网页的动效慢一档。

**三、画面是调过色的。** 降饱和、提对比、四角压暗，再加**会动的胶片颗粒**
（每帧微移噪点图案——静止的噪点不像胶片）。

**四、播放时控制条可隐去。** 放映播放中鼠标静止两秒半且控件没有键盘焦点时，上梁与铜尺隐去；移动、暂停或操作键盘即回。

**衔接**：镜头随讲解片段切换到相应地点，战役开场为镜头就位留出时间。章节、字幕与行军由统一播放控制器管理，暂停或缓冲时不独自前进。放映只改变布局，不重置播放进度。

**对齐**：放映时左右所有元素（幕次、字卡的细线与标题、解说、易主提示、纪年、比例尺）
落在同一条基线上（`--cine-x`）；常规视图里简册栏距、盘内器具边距也各归一个变量（`--pad` / `--edge`），
不再是二十二、三十、三十四、四十并存。

此外：解说压成**下三分之一**（朱砂给战事、铜色给讲解），角上是幕次与纪年，
镜头始终有极缓的呼吸与横移，讲到某地便缓缓移过去——七十一条非战之事里有七十条
带了地点，说「商鞅第一次变法」时镜头在栎阳，说「稷下学宫」时在临淄。镜头一律夹在
诸夏范围内，不会漂到海上。`Esc` 退出。

镜头飞行时先缩放缓存画面，讲解镜头按280ms节流重画。
旧版曾测得放映帧间隔 p50 / p95 为16.8ms；这不是本次音频改造后的性能测量。

## 声与同步

配音由本地 Qwen3-TTS 0.6B Base 按已认可的参考声线预生成，覆盖六幕、71条非战役事件与30场战役的97步讲解，共204段。网页只加载静态 MP3，不依赖系统中文嗓音。显示稿保留古文与史料说明，发音修订和音频生成分开维护。

音频实际播放位置是字幕和行军的共同时间轴。暂停、续播、进度拖动、倍速和战役步骤切换一起生效；切到后台会暂停。加载失败时提供重试或无声继续，不会悄悄跳过讲解或切换另一种声音。

查看地图时保存一个可返回的讲解断点；可独立听其他事件，再返回原进度。首次推演包含当前年份全部事件，前221年的最后几条也会完整讲完。前479年的孔子卒属于范围外史事，可独立听讲，地图明确显示前475。

重建方法、离线包、资源上限和许可见 [docs/VOICE.md](docs/VOICE.md)；实际检查与未覆盖项见 [docs/QA.md](docs/QA.md)。

```bash
npm test
node tools/verify-voice.mjs
node build.mjs
```

## 手感

以下性能数字保留为旧版优化记录；本次实际检查与限制见配音文档及交付检查记录。

第一版逐帧全量重绘整张盘，静置时也在烧 CPU；换一年要重建一次国力面板的 DOM；
平滑滚动被逐年重启而互相打断；滚轮按固定倍率缩放，触控板一扫就冲到底。实测（同机同脚本）：

| 场景 | 改前 | 改后 |
| --- | --- | --- |
| 静置 | 帧 p95 617ms，长帧 17 | 17ms，长帧 0 |
| 自动推演 6 秒 | 长帧 67 | 2 |
| 拖动铜尺横扫全程 | 长帧 101，DOM 重建 67 | 21，重建 8 |
| 滚轮缩放 | 长帧 10 | 0 |
| 点开战役 | 帧 p95 167ms | 50ms |

做法：盘面画进离屏画布缓存，只在视角、年份、图层变了才重绘，每帧只重画会动的几层；
山痕、郡界、国界从上千次 `stroke` 合并成几条 `Path2D`；化外斜纹改用图案填充；
易主过渡改为两张盘面交叠淡出，而非逐帧重算配色；镜头飞行期间先缩放缓存的那张，落定再重绘；
拖动铜尺时不做过渡动画且重绘限流；滚轮改按位移取指数并夹住单次幅度。
`prefers-reduced-motion` 下镜头直接就位、战事标记不再脉动。

另有一处只在首屏出现的错：开页时 ResizeObserver 的首次回调以**同一尺寸**重设画布，
而给 `canvas.width` 赋值哪怕是原数也会清空画布；缓存键未变，下一帧便不重画——
于是盘面一片黑，要等第一次交互才出现。现尺寸不变即不碰画布，尺寸变了则作废缓存。

`src/geo.js` — 投影、半平面裁剪求 Voronoi、邻接判定、样条平滑。
`src/table.js` — 沙盘渲染：高程场烙山、斜光晕渲、疆域镶嵌、兵棋、推演。
`src/app.js` — 铜尺、大事记、国力、案上和统一播放控制器的界面联动。
`src/player.js` — 媒体播放、暂停、缓冲、跳转与断点。
`src/narration.js` — 历史数据对应的讲解片段与完整年代队列。
`src/sound.js` — 战事落定时的编钟合成；中文旁白使用预生成音频。
`tools/subset-font.mjs` — 把 Noto Serif SC Bold 裁到本站用到的 1467 字，内嵌为 woff2，详见 [assets/README.md](assets/README.md)。

`build.mjs` 拼单文件时会**查顶层重名**：各模块本有独立作用域，拼在一起若有同名常量便会静默相撞
（汉字数目转换一度在两处各写一份，即由此暴露），故让构建直接失败而非靠肉眼。

## 部署

公开网站为 [GitHub Pages 沙盘](https://wowayou.github.io/warring-states-sandtable/)。**只发布完整 `dist/`，不上传仓库根目录**。普通构建不需要模型权重、参考原录音或本地 `work/`；它校验已提交的静态音频和听审元数据。

- **GitHub Pages** — Source 为 GitHub Actions；`.github/workflows/pages.yml` 在公开仓库的 `main` 上运行测试、构建和文件白名单校验，再发布 `dist/`。相关源文件变更才触发；手动发布也只允许 `main`。单次10分钟超时、并发组1、制品最多25MiB且保留1天。没有生成配音、安装浏览器、扩大 runner 或调整付费计划。
- **其他静态托管** — 构建命令 `node build.mjs`，输出目录 `dist`；使用其他服务前另核对其当前费用与限额。
- **本地 / 离线** — 保留整个 `dist/` 或完整解压 ZIP，不只复制 HTML。`assets/`、`voices/`、`review/` 均需保持相邻。Chromium解压断网流程已验证；本机Linux WebKit/WPE多页文件播放的原生崩溃作为用户已接受的已知限制保留，真实Safari尚未验证，见 [docs/QA.md](docs/QA.md)。

内容存在未处理的听审疑点时，正式构建拒绝发布这些候选。`node build.mjs --local-review` 只生成带「本地试听草稿」标识的 `work/multi-voice/preview/`，不改正式 `dist/` 或正式 ZIP；该目录包含两条待审女声，不得当作已验收发布包。

## 关于准确度

疆域为**概貌示意**，据主流复原图简化，以事件为界分段切换，非逐年精确。
几处已知的取舍：南阳（宛）本属楚，垂沙之战（前301）后入韩，前291 入秦；
上党在韩赵魏间犬牙交错，此处作前453 属韩、前262 归赵、前260 入秦；
战国初年晋公室尚存至前376，盘上则于前453 三家分晋时即撤。

**年代不能确指的标「约」**（如李悝相魏、稷下学宫、李冰守蜀、李牧破匈奴），
史料歧出处在正文里写明「一说」。主要的取舍与依据：

| 事 | 此处所取 | 依据与异说 |
| --- | --- | --- |
| 周王纪年 | 元王前475—前469，贞定王前468—前441 | 哀王、思王皆薨于前441，不另立元年；周亡后改用秦王纪年，秦昭襄王续其本年数（前255 为五十二年，非元年） |
| 赵襄子灭代 | 前475 | 清华简《系年》与《赵世家》「襄子元年，越围吴」；《史记》年表作前457 |
| 魏徙大梁 | 前361 | 《竹书纪年》；《史记》作前340 |
| 魏文侯元年 | 约前445 | 《竹书纪年》推算；《史记》作前424 |
| 楚灭越 | 前306 | 一说前334（楚威王） |
| 苏秦 | 前287 约五国攻秦 | 马王堆帛书《战国纵横家书》：苏秦晚于张仪，《史记》前333 佩六国相印之说多误 |
| 都城 | 秦：雍→栎阳（前383）→咸阳（前350）；韩：平阳→宜阳→阳翟→新郑；赵：晋阳→中牟（前423）→邯郸（前386）；楚：郢→陈→钜阳（前253）→寿春；越：会稽→琅琊（前468）→吴 | 中牟故址有异说，此取今鹤壁一带 |
| 黄河 | 自宿胥口北折，经濮阳、德州、沧州入渤海 | 即《汉书·地理志》之河；今自东营入海那一段，战国时是济水 |
| 兵力 | 只写史籍所载 | 史无明文的数目（如长平「秦六十万」、晋阳「十万」）不写 |

国力栏只给所辖地块数，与按田赋人口估算的相对长短。「地」为沙盘上的地理单元，非秦制三十六郡；
此前把分量折算成「带甲若干万」，那是编出来的数，已去掉。

现收大事 101 条（其中战役 30 场），分战事、变局、纵横、兼并、迁都、学术、百工七类。
